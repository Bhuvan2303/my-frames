# My Frames photo assets

The four `.webp` files currently in this folder are lightweight visual placeholders so the site renders immediately. Replace them with your real photographs using the same filenames:

- `my-frames-hero.webp`
- `my-frames-place.webp`
- `my-frames-people.webp`
- `my-frames-detail.webp`

The app references them with `/photos/...`. Because Vite is configured with `publicDir: 'client/public'`, the required repository structure stays exactly as requested.
